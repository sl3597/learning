# 深度学习最小必要知识

> 要读懂 VLA 论文，你不需要成为深度学习专家，但必须知道"训练一个模型"到底在干什么。这一章只讲**后面章节一定会用到**的概念，不多不少。

## 学习目标

- 能解释"参数""损失""梯度下降"三个词，以及它们之间的关系
- 能看懂一段 10 行左右的 PyTorch 训练代码
- 能说出训练集 / 验证集 / 测试集的作用，判断什么是过拟合
- 能粗略估算一个模型需要多少显存

## 前置知识

- 需要先读：[01 什么是机器人学习](01-what-is-robot-learning.md)
- 会用 Python 定义函数和写 for 循环

## 核心概念

| 术语 | 一句话解释 | 类比 |
|---|---|---|
| **神经网络** | 一堆可调参数组成的函数，输入数字、输出数字 | 一台有几百万个旋钮的机器 |
| **参数（权重）** | 神经网络里可以被训练调整的数字 | 机器上的旋钮 |
| **损失（Loss）** | 衡量"模型输出"和"正确答案"差多远的一个数 | 考试扣的分 |
| **梯度** | 每个参数往哪个方向拧、拧多少能让损失变小 | 每个旋钮上贴的"顺时针拧会更好"的标签 |
| **梯度下降** | 反复按梯度方向微调参数，让损失越来越小 | 蒙着眼下山，每一步往最陡的下坡方向迈 |
| **过拟合** | 模型把训练数据背下来了，换新数据就不行 | 只背了题库答案，换题就不会 |
| **显存（VRAM）** | GPU 上的内存，模型参数和中间结果都放这里 | 工作台的面积，太小摆不下工具 |

## 详细讲解

### 2.1 神经网络就是"带旋钮的函数"

先忘掉"神经"这个词。一个神经网络本质上是一个函数 $f_\theta(x)$：

- $x$ 是输入（一张图片展平成的数字、一句话的编码……）
- $\theta$（theta）是**参数**，一大堆数字，模型训练前随机初始化
- 输出是另一组数字（分类概率、机器人下一步的关节角……）

最简单的神经网络是"线性变换 + 非线性激活"反复堆叠：

$$h = \text{ReLU}(W_1 x + b_1), \quad y = W_2 h + b_2$$

$W$、$b$ 都是参数。$\text{ReLU}(z)=\max(0,z)$ 是激活函数，作用是让网络能表达"拐弯"的关系而不只是直线。

> 💡 要点：论文里说"模型有 7B 参数"，意思就是 $\theta$ 里有 70 亿个数字。每个数字用 16 位浮点（2 字节）存，光参数就要 14 GB。

### 2.2 训练 = 让损失变小

训练的目标是找一组 $\theta$，让模型在训练数据上的**损失**尽量小。

损失函数把"预测"和"真实值"的差距变成一个数。两个最常见的：

- 回归（预测连续数值，如关节角）：均方误差 $L = \frac{1}{N}\sum (y_{\text{pred}} - y_{\text{true}})^2$
- 分类（预测类别，如离散动作 token）：交叉熵 $L = -\sum y_{\text{true}} \log y_{\text{pred}}$

**梯度下降**的做法只有一句话：算出损失对每个参数的梯度 $\nabla_\theta L$，然后 $\theta \leftarrow \theta - \eta \nabla_\theta L$。$\eta$ 叫**学习率**，决定每步迈多大。

实际训练中每次只用一小批数据（一个 **batch**，比如 32 条样本）算梯度，这叫**随机梯度下降（SGD）**；常用的改进版叫 **Adam / AdamW**，你在 VLA 论文的实验设置里一定会看到。

### 2.3 十行 PyTorch 看懂训练循环

```python
import torch, torch.nn as nn

model = nn.Sequential(nn.Linear(10, 64), nn.ReLU(), nn.Linear(64, 7))  # 输入10维状态，输出7维动作
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4)
loss_fn = nn.MSELoss()

for step in range(1000):
    x, y_true = get_batch()            # 从数据集取一批 (状态, 动作)
    y_pred = model(x)                  # 前向：算预测
    loss = loss_fn(y_pred, y_true)     # 算损失
    optimizer.zero_grad()              # 清掉上一步的梯度
    loss.backward()                    # 反向传播：算梯度
    optimizer.step()                   # 更新参数
```

这 10 行就是所有深度学习训练的骨架。VLA 训练代码再长，核心也是这个循环，只是 `model` 变成几十亿参数、`get_batch` 变成从机器人数据集里读图像和动作。

### 2.4 训练集、验证集、测试集与过拟合

把数据分成三份：

| 数据集 | 用途 | 模型能"看到"吗 |
|---|---|---|
| 训练集 | 算梯度、更新参数 | 看到 |
| 验证集 | 调超参数、决定什么时候停 | 只看损失，不更新参数 |
| 测试集 | 最终汇报成绩 | 完全不看，直到最后 |

训练时常见的现象：训练损失一直在降，验证损失先降后升。这就是**过拟合**——模型开始"背"训练数据的细节了。

> ⚠️ 注意：机器人领域的"测试"往往是真机实验，成本很高。论文里的"成功率"通常来自几十次真机试验，数值波动大，比较时要看试验次数。

### 2.5 GPU 和显存：为什么训练这么贵

神经网络的计算几乎全是矩阵乘法，GPU 擅长并行做这件事。训练时显存里要放：

1. **模型参数**：7B 模型用 bf16 约 14 GB
2. **梯度**：和参数一样大，再 14 GB
3. **优化器状态**：AdamW 要存两份额外的统计量，再约 28 GB（fp32）
4. **激活值**：前向传播的中间结果，和 batch size、图像分辨率成正比

粗略估算：**全量微调一个 7B 模型至少需要 60~80 GB 显存**，一张 24 GB 的消费级显卡放不下。这就是为什么第 08 章要讲 LoRA 这类"只训练一小部分参数"的方法。

**推理**（只做前向，不算梯度）只需要放参数和少量激活，7B 模型 bf16 推理约 16 GB 就够。

> 🔍 深入：bf16 / fp16 / fp32 是不同精度的浮点数格式。训练常用 bf16 做前向反向、fp32 存优化器状态，这叫混合精度训练。

## 动手练习

1. 安装 PyTorch，把 2.3 节的代码补上一个假的 `get_batch()`（随机生成 `x` 和 `y_true`），跑 1000 步，打印损失。

<details><summary>参考做法</summary>

```python
def get_batch():
    x = torch.randn(32, 10)
    y_true = x[:, :7] * 2 + 1   # 人为设定一个线性关系
    return x, y_true
```

把这段放在训练循环前面，每 100 步 `print(step, loss.item())`，应该看到损失从几十降到接近 0。
</details>

2. 把学习率改成 `1e-1` 和 `1e-7` 各跑一次，观察损失曲线有什么不同。

<details><summary>参考做法</summary>

`1e-1` 太大，损失可能震荡甚至变成 NaN；`1e-7` 太小，1000 步几乎不动。这就是为什么论文都会写明学习率。
</details>

## 常见错误与排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 损失变成 `nan` | 学习率太大，或输入没归一化 | 调小学习率；把输入缩放到 0~1 或标准化 |
| 训练损失很低但真机效果差 | 过拟合，或训练/测试分布不一致 | 增加数据多样性，用验证集早停 |
| `CUDA out of memory` | 显存不够 | 减小 batch size、降低分辨率、用 LoRA、用梯度检查点 |
| 忘了 `optimizer.zero_grad()` | 梯度会累加 | 每一步更新前清零 |

## 小结

- 神经网络 = 带几百万到几十亿个可调参数的函数。
- 训练 = 用梯度下降反复调参数让损失变小；核心就是 10 行代码的循环。
- 训练 / 验证 / 测试三份数据各司其职；验证损失回升就是过拟合。
- 显存估算：训练约需参数量 × 16 字节以上；推理约需参数量 × 2 字节。

## 自测题

1. 一个 3B 参数的模型，用 bf16 做推理，参数大约占多少显存？

<details><summary>答案</summary>3B × 2 字节 = 6 GB，再加激活值，大约 7~8 GB。</details>

2. 为什么不能用测试集来调学习率？

<details><summary>答案</summary>一旦根据测试集的结果调整任何决策，测试集就"泄露"进了训练过程，最终汇报的成绩会虚高，无法反映真实泛化能力。</details>

3. `loss.backward()` 和 `optimizer.step()` 分别做什么？

<details><summary>答案</summary>`backward()` 计算损失对所有参数的梯度并存到每个参数的 `.grad` 上；`step()` 根据这些梯度和优化器规则更新参数值。</details>
