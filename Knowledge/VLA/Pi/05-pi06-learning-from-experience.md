# π*0.6：用 RECAP 从自身经验中学习

> 前几章的 π 模型都靠"看人示范"来学。这一章讲 Physical Intelligence 在 2025 年 11 月发布的 π*0.6（读作 pi-star 0.6）：它给 π0.6 加了一套叫 **RECAP** 的强化学习配方，让机器人从自己的成功和失败里继续变强，把"有时能成功"推进到"连续工作十几个小时"。

## 学习目标

- 能解释为什么只靠模仿学习的 VLA 很难"每次都成功"，并说出复合误差是什么
- 能说出 RECAP 用的三类数据和三个训练阶段
- 能用大白话讲清楚价值函数、优势、优势条件化，以及它们怎么解决"功劳分配"
- 能读懂论文的吞吐量 / 成功率结论，知道 RECAP 在哪些任务上帮助最大
- 能列出这套方法还没解决的问题

## 核心概念

| 术语 | 一句话解释 | 类比 |
|---|---|---|
| **复合误差（compounding errors）** | 犯一个小错就进入训练数据没见过的状态，接着犯更大的错 | 第一步偏半步，不纠正就越走越偏 |
| **强化学习（RL）** | 不靠人示范，靠"结果好不好"的反馈改进策略 | 练投篮：进了就记住这个姿势 |
| **离线 RL（offline RL）** | 只用已收集好的数据做 RL，训练时不与环境交互 | 看录像复盘，而不是现场打 |
| **价值函数（value function）** | 给当前画面打分：离完成任务还有多远 | 下棋软件的"局面评估" |
| **优势（advantage）** | 做了这个动作之后，价值涨了还是跌了 | 走完一步棋，评分的变化量 |
| **优势条件化（advantage conditioning）** | 训练时把"这步好不好"当成输入；用时固定要求"走好棋" | 教练在录像上标"正面 / 反面教材" |
| **遥操作纠正（intervention）** | 机器人自己跑，出错时专家接管手柄纠正 | 教练在你做错时伸手扶一把 |

## 详细讲解

### 5.1 为什么只靠示范学不到"每次都成功"

π0、π0.5 全是**模仿学习**：看人类遥操作的示范，学着复制。这条路能做到"一半时间成功"，却很难"每次都成功"，原因是复合误差：模型总会犯小错（夹爪偏一点、没夹住），错一次之后看到的画面就和训练数据不一样了，更容易犯更大的错。语言模型没这个问题，因为它的输出不会反过来改变输入；机器人是在真实世界里**持续交互**的，错误会累积。

补救思路是让机器人用**自己跑出来的数据**继续训练，专门修它在部署里真正会犯的错。但直接拿这些数据做模仿，等于照着自己的错误再学一遍。关键问题变成：**怎么从质量参差不齐的经验里提取有用的训练信号？** 博客的比方是学装纸箱：先看人示范，再让教练在你出错时纠正，最后自己反复练。此前的 VLA 只做了第一步，RECAP 把三步做全。

### 5.2 π0.6：更大的骨干，更"听得懂条件"的 VLA

RECAP 的基座是 **π0.6**，论文说它在 π0.5 之上有三处改进：预训练数据加入更多机器人平台；骨干换成 **Gemma 3 4B**；动作专家扩大到 **860M** 参数。动作专家仍用流匹配生成 50 Hz 的关节角 + 夹爪动作块，训练沿用 [04 章](04-pi05-open-world-and-knowledge-insulation.md)的知识隔离（KI）配方：主干同时预测 FAST 离散动作 token 和子任务文本，动作专家用 stop gradient 隔开。推理时先输出子任务文本（如"拿起咖啡杯"），再生成动作。

> ❓ 待解决：博客写"基于 5B 参数的视觉语言模型"，论文写"基础 VLM 是 Gemma 3 4B"，可能是是否计入视觉编码器的口径差异，需对照模型卡核实。

π0.6 的提示词可以"异构"：除任务指令外还能输入描述执行质量的元数据。RECAP 正是利用这一点，再加一条文本条件 `Advantage: positive` / `Advantage: negative`。加了这个条件的模型就叫 π*0.6。

### 5.3 RECAP：示范、纠正、自主练习三合一

**RECAP** 全称 RL with Experience and Corrections via Advantage-conditioned Policies。它反复执行三个子程序：**采数据**（让当前 VLA 跑任务，每条轨迹标成功 / 失败，可选专家纠正）→ **训练价值函数**（用迄今全部数据）→ **优势条件化训练策略**（算出每个动作的优势，转成"正 / 负"指示符喂给 VLA）。

```mermaid
flowchart LR
  D[示范数据<br/>数万小时、多平台] --> V[价值函数<br/>离成功还有几步]
  V --> A[算优势<br/>贴 正/负 标签]
  A --> P[优势条件化训练<br/>所有数据都用]
  P --> R[上机器人部署<br/>自主 rollout + 专家纠正]
  R -->|成功/失败标签<br/>加入数据集| V
```

| 阶段 | 用什么数据 | 做什么 |
|---|---|---|
| 离线 RL 预训练 | 数万小时多任务、多机器人示范 | 先训价值函数，再用优势指示符训练通用 VLA，得到 π*0.6 基座 |
| 任务微调（SFT） | 目标任务的示范 | 指示符固定为"正"，相当于普通监督微调 |
| 从经验中学习（可迭代） | 自主 rollout + 纠正 | 重训价值函数，更新优势标签，再微调策略；每轮从预训练检查点出发，避免漂移 |

> 💡 要点：三个阶段用同一套子程序，变的只是数据。论文发现**一轮**经验学习往往就有明显提升。

### 5.4 价值函数：给每一帧打"离成功还有多远"的分

奖励极其简单：每条轨迹只有一个成功 / 失败标签。由此定义价值 = **（负的）距离成功还需要的步数**，失败轨迹给一个很大的负值，再按每个任务的最大长度归一化。实现上这是**分布式价值函数**：输出落在若干离散分桶上的概率，用交叉熵训练，再按桶的期望还原成连续值。它和 VLA 架构相同，但骨干只有 **670M**（同样从 Gemma 3 初始化），并混入少量网页数据防过拟合。骨干小，训练 VLA 时就能**边训边算**每个样本的优势。

这正是强化学习里**功劳分配**问题的解法：咖啡做失败是因为插不进手柄，但真正的错误可能发生在更早的"抓取角度不对"。价值函数会在抓歪那一刻就掉分，责任被正确记在抓取上。

### 5.5 优势条件化：把好坏当成输入，而不是筛掉坏数据

有了价值函数，怎么得到更好的策略？策略梯度（PPO 等）在流匹配模型上算不出精确似然、大模型上难稳定；加权回归（AWR）实际上丢掉了大部分数据。RECAP 的做法是**全部数据都做监督训练，只多一个输入**：优势是否超过任务相关阈值决定指示符正负，专家纠正的动作一律标为正。推理时固定输入 `Advantage: positive`，模型就输出比训练数据更好的动作。训练中有 30% 概率随机去掉指示符，推理时也能用无分类器引导（CFG）进一步"锐化"。

> 🔍 深入：这和 CFGRL 同源：把"动作会带来改进"当作条件，用贝叶斯公式可证明条件化后的策略不差于原策略。论文用阈值而不是 CFG 权重来控制"多激进"，因为权重太大会把动作推到分布边缘、动作变粗暴。

> ❓ 待解决：阈值的具体分位数、优势估计的 lookahead 步数、价值分桶数量在 HTML 版正文里被公式吞掉，需查 PDF 附录 A-F。

### 5.6 任务与结果

实验机器人是固定双臂系统：两条 6 自由度机械臂 + 平行夹爪，50 Hz 关节位置控制，三个相机。四个任务都是 5~15 分钟的长流程：叠衣（T 恤与短裤，200 秒内）、多样叠衣（11 类衣物，只统计最难的纽扣衬衫，500 秒内）、双份浓缩咖啡（取手柄、磨豆、压粉、锁入、萃取、上桌，200 秒内）、装纸箱（真实工厂，折箱、贴标、入货箱，600 秒内）。

对比 π0.5 预训练、π0.6 监督预训练、π\*0.6 离线 RL 预训练、π\*0.6 离线 RL + SFT、完整 π\*0.6 五个模型，指标是**吞吐量**（每小时成功次数）和成功率。结论：

- 加入机器人上收集的经验后，多样叠衣和咖啡的吞吐量**提高 2 倍以上**，失败率大约**减半**；除多样叠衣外，最终模型成功率都在 **90% 以上**。
- 迭代实验：T 恤任务只用自主数据，每轮 300 条轨迹，第一轮成功率即超过 90%；装纸箱每轮 600 条自主 + 360 条纠正，两轮后吞吐量翻倍。
- 同样的数据换成 AWR 或 PPO，都远不如优势条件化；要求领口朝上的 T 恤实验里，纯 RL 两轮就去掉了这个失误模式。

博客的部署展示：连续做咖啡 13 小时（博客写从早 5:30 到晚 11:30），在没见过的家里连续叠 50 件新衣物两小时以上，在工厂装并贴标 59 个巧克力包装箱。

> ❓ 待解决：各模型吞吐量和成功率的具体数值只在论文图 7、图 8 里，需对照 PDF 补表。

### 5.7 局限

论文自己列了三条：系统不是全自动的（成功标签、纠正、场景复位都靠人）；探索很"贪心"，只靠策略随机性和人工纠正；每轮是"采一批、训一次"的离线迭代，不是实时在线 RL。π*0.6 是否开源权重，论文和博客都没提。

> ⚠️ 注意：RECAP 的提升是**在同一任务上反复采数据**换来的，解决的是"熟练度"，不是 π0.5 那种"换个家还能用"的泛化。两者互补，别混为一谈。

## 常见错误与排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 以为 RECAP 是"扔掉失败数据只学成功的" | 混淆了过滤式模仿和优势条件化 | RECAP 用**全部**数据，只多输入一个好 / 坏指示符 |
| 以为价值函数要人工写奖励 | 没注意奖励定义 | 只需每条轨迹一个成功 / 失败标签 |
| 推理时忘了设置优势条件 | 指示符训练时被随机去掉过 | 推理固定输入 `Advantage: positive` |
| 每轮从上一轮模型继续训，越训越漂 | 论文发现从预训练检查点出发更稳 | 价值函数和策略都从预训练检查点微调 |

## 小结

- 模仿学习受复合误差限制；RECAP 用机器人自己的经验修它真正会犯的错。
- 三类数据（示范、纠正、自主 rollout）× 三个阶段（离线 RL 预训练、SFT、经验迭代），子程序相同，只换数据。
- 价值函数只需成功 / 失败标签，预测"距成功还有几步"，解决功劳分配。
- 优势条件化不筛数据，把"好 / 坏"当输入，推理时要求"好"，比 PPO、AWR 更适合流匹配大模型。
- 最难任务吞吐量翻倍、失败率减半；但仍依赖人工标注、纠正和复位。

## 自测题

1. 为什么复合误差对机器人策略是大问题，对语言模型却不是？

<details><summary>答案</summary>机器人的输出会改变真实环境、改变下一步输入，错误把它带进训练数据没覆盖的状态并放大；语言模型的输出是静态的，不会反过来改变输入分布。</details>

2. RECAP 的价值函数输入是什么、输出是什么？它怎么解决"功劳分配"？

<details><summary>答案</summary>输入和 VLA 一样：图像 + 语言指令；输出是"距成功还有多少步"的分布。某个动作之后价值掉了，说明问题出在这个动作上，即使失败要很久以后才显现。</details>

3. 优势条件化和 AWR 的根本区别是什么？

<details><summary>答案</summary>AWR 按优势加权，相当于丢掉大部分低优势数据；优势条件化保留全部数据，把优势正负作为额外输入，推理时固定选"正"。</details>
