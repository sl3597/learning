# 用世界模型做规划与控制

> 有了"能预演"的模型，下一步就是"怎么利用预演来选动作"。本章用最少的公式讲清 MPC、CEM、MPPI，以及为什么预演太长会"越想越错"。

## 学习目标
- 能描述"想象 rollout → 评分 → 选动作"的通用规划框架。
- 能解释 MPC 的"滚动时域"思想。
- 能对比 CEM 与 MPPI 的采样更新方式。
- 能说明误差累积的成因及三种缓解手段。
- 能判断一个任务该"规划"还是该"直接用策略"。

## 前置知识
- 需要先读：[隐状态动力学与 Dreamer](02-latent-dynamics-and-dreamer.md)、[JEPA 与表征预测](04-jepa-and-latent-prediction.md)

## 核心概念
| 术语 | 一句话解释 | 类比 |
|---|---|---|
| **代价 / 奖励函数** | 给一条预演轨迹打分的规则 | 评委打分表 |
| **规划视野 $H$** | 一次预演多少步 | 下棋往前看几步 |
| **MPC（模型预测控制）** | 每步都重新规划，只执行第一个动作 | 边走边看导航 |
| **CEM（交叉熵方法）** | 采样—筛精英—收紧分布的迭代优化 | 海选→复赛→决赛 |
| **MPPI** | 按得分加权平均所有样本来更新 | 按评分加权投票 |
| **误差累积（compounding error）** | 多步预测误差逐步放大 | 传话游戏越传越离谱 |
| **集成（ensemble）** | 训练多个模型，用它们的分歧度量不确定性 | 多问几个专家，看他们吵不吵 |

## 详细讲解
### 6.1 通用框架

```text
给定当前状态 z_t、目标（图像/奖励函数）
重复：
  1. 生成 N 条候选动作序列 a_{t:t+H}
  2. 用世界模型 rollout 得到 N 条预测轨迹 ẑ_{t+1:t+H+1}
  3. 按代价 J = Σ c(ẑ_k, a_k) 打分
  4. 用某种优化器（CEM/MPPI/梯度）更新候选分布
输出最优序列
```

代价常见写法：到目标表征的距离（V-JEPA 2-AC 用 $\|\hat z - z_{goal}\|$）、负的预测奖励（Dreamer/PlaNet 用奖励头）、或两者加上安全惩罚（接触力过大、离开工作空间）。

### 6.2 MPC：只执行第一步

**模型预测控制**把 6.1 的优化放进每一个控制周期：规划 $H$ 步，只执行 $a_t$，下一个周期观察到新的 $z_{t+1}$ 后**重新规划**。好处是每步都用真实观测纠偏，模型误差不会无限传递；代价是每步都要算一次优化——这就是 V-JEPA 2-AC 每个动作 16 秒的来源。

> 💡 要点：MPC 的本质是"用频繁重规划换取对模型误差的鲁棒性"。模型越差，越需要短视野 + 高频重规划。

### 6.3 CEM 与 MPPI

两者都是"不求导、靠采样"的优化器，适合世界模型这种黑箱。

| | CEM | MPPI |
|---|---|---|
| 采样 | 从高斯 $\mathcal N(\mu,\sigma^2)$ 采 $N$ 条 | 同 |
| 更新 | 取代价最低的 $K$ 条（精英），用它们的均值/方差作新 $\mu,\sigma$ | 所有样本按权重 $w_i \propto \exp(-J_i/\lambda)$ 加权平均作新 $\mu$ |
| 直觉 | 淘汰制 | 投票制，温度 $\lambda$ 控制"多大程度只信最好的" |
| 迭代 | 多轮（V-JEPA 2-AC：10 轮） | 常只做 1 轮，适合高频控制 |

$$
\mu_{\text{new}} = \frac{\sum_i w_i\, a_i}{\sum_i w_i},\qquad w_i = \exp\!\left(-\frac{J_i - \min_j J_j}{\lambda}\right)
$$

> 🔍 深入：如果世界模型可微（Dreamer 的隐空间模型就是），还可以直接对动作求梯度做优化，甚至像 Dreamer 那样干脆训练一个策略网络，把"每步在线优化"摊销成"一次前向"。

### 6.4 误差累积

设每步预测相对误差为 $\epsilon$，$H$ 步后误差大致按 $(1+\epsilon)^H$ 增长（粗略直觉，非严格）。$\epsilon=5\%$ 时，10 步后约 1.6 倍，50 步后约 11 倍。缓解手段：

1. **缩短视野 + MPC 重规划**（最常用）。
2. **用价值函数代替长视野**：Dreamer 只想象 15 步，更远的收益交给 Critic 估计。
3. **训练时就做多步预测**：PlaNet 的 latent overshooting 让模型在训练时也被要求多步一致。

### 6.5 不确定性与集成

模型在没见过的区域会"自信地胡说"。常用做法：训练 $M$ 个世界模型（不同初始化/数据顺序），对同一动作序列做 rollout，**预测分歧越大 → 越不可信**，在代价里加惩罚或直接丢弃这些候选。这类似 PETS 等经典 MBRL 的做法。

### 6.6 规划还是直接出策略？

| 情况 | 建议 |
|---|---|
| 目标多变、任务少量演示、可以接受秒级延迟 | 规划（如 V-JEPA 2-AC 零样本） |
| 需要高频（≥10 Hz）闭环控制 | 直接策略（VLA），或把规划结果蒸馏成策略 |
| 安全关键、需要在执行前验证 | 规划或"策略提候选 + 世界模型过滤" |
| 接触丰富、力反馈关键 | 目前两者都难；需力感知模型（见 [ForceVLA](../VLA/ForceVLA/00-README.md)）与短视野 MPC |

## 动手练习
1. 手算一轮 CEM：候选代价为 [5, 2, 9, 1, 7, 3]，精英数 2，写出被保留的候选及其均值。
<details><summary>参考做法</summary>

精英是代价 1 和 2 的两条（索引 3 和 1）。新均值 = 它们动作的平均值（题中未给动作值，答出"取索引 1、3 的动作求平均"即可）。
</details>

2. 用 MPPI 公式，$\lambda=1$，代价 [1, 2, 3]，求三个权重（归一化后）。
<details><summary>参考做法</summary>

未归一化：$e^0=1, e^{-1}\approx0.368, e^{-2}\approx0.135$；和 ≈1.503；权重 ≈ [0.665, 0.245, 0.090]。
</details>

3. 若一个任务要求 20 Hz 控制，而规划器每步需 0.5 秒，给出两种让系统可用的方案。
<details><summary>参考做法</summary>

① 把规划结果蒸馏/模仿成一个策略网络，推理只需一次前向；② 降低规划频率：规划一次输出 10 步动作块，由低层控制器以 20 Hz 插值执行，期间不重规划。
</details>

## 常见错误与排查
| 现象 | 原因 | 解决 |
|---|---|---|
| 规划出的动作在真机上撞东西 | 模型在该区域不可信 | 加集成不确定性惩罚、加安全约束、缩短视野 |
| 视野越长效果越差 | 误差累积 | 缩短 $H$，用 Critic 或 MPC |
| CEM 收敛到局部最优 | 初始方差太小或精英数太少 | 增大初始 $\sigma$、增加样本数、加入上一周期解作为热启动 |
| 规划太慢 | 样本数 × 视野 × 轮数太大 | 降分辨率/用隐空间模型、减少轮数、改 MPPI 单轮 |

## 小结
- 规划 = 采样候选 → 世界模型预演 → 打分 → 优化分布。
- MPC 每步重规划只执行第一步，用真实观测纠偏。
- CEM 淘汰制，MPPI 加权制；可微模型还能用梯度。
- 误差累积靠短视野、价值函数、多步训练目标缓解；集成分歧度量不确定性。
- 高频控制用策略，多变目标/安全验证用规划，或两者结合。

## 自测题
1. MPC 为什么"只执行第一个动作"？
<details><summary>答案</summary>下一周期会得到新的真实观测并重新规划，从而不断用真实信息纠正模型误差。</details>

2. CEM 和 MPPI 更新分布的方式有何不同？
<details><summary>答案</summary>CEM 只用精英样本重新估计分布；MPPI 用所有样本按 exp(-代价/λ) 加权平均。</details>

3. Dreamer 如何在不加长想象视野的情况下考虑长期收益？
<details><summary>答案</summary>用 Critic（价值函数）估计想象终点之后的收益。</details>

4. 集成模型如何帮助规划？
<details><summary>答案</summary>多个模型预测分歧大的区域被视为不确定，在代价中惩罚或排除这些候选。</details>
